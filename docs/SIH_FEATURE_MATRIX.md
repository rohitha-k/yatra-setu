# YatraSetu — Smart India Hackathon Feature Matrix

This matrix summarizes the features implemented in the YatraSetu MVP, the specific problems they solve, the underlying technologies utilized, and their current verification status.

| Feature Name | Problem Solved | Technology | Verification Status |
| :--- | :--- | :--- | :--- |
| **Budget Planning Wizard** | Solves cost inflation by planning all services inside budget targets. | Node Express optimization heuristics | **WORKING** |
| **Budget Status Indicators** | Communicates budget health immediately without overwhelming the user. | Dynamic frontend calculation wrappers | **WORKING** |
| **Own-Vehicle Calculator** | Prevents unexpected travel expenses (fuel, highway tolls). | NHAI coordinates + mileage sliders | **WORKING** |
| **Interactive YatraMap** | Eliminates highway safety uncertainty and overlays EV/mechanic locations. | Leaflet + OpenStreetMap tile layers | **WORKING** |
| **Explainable Trust Score** | Validates guesthouse quality and licenses to prevent scam listings. | 0–100 weighted formula | **WORKING** |
| **AI Travel Assistant** | Simplifies itinerary planning via conversational inputs. | Regex intent parsing + budget optimizer | **WORKING** |
| **RBAC Security Middleware** | Prevents tourists or vendors from accessing administrative controls. | JWT token decryption + middleware guards | **WORKING** |
