# Yatra Setu — Furkot Feature Matrix & Implementation Audit

*Status as of 17 September 2026. Audited against the active Yatra Setu repository.*

## Architecture & Storage Confirmation
- **Primary Database**: MongoDB via Mongoose (`backend/config/db.js`).
- **Resilient Fallback**: Local File-based JSON adapter (`backend/data/db.json` managed via `dbAdapter` in `backend/config/db.js`), **not** SQLite. An automatic in-memory / JSON file sync handles queries when MongoDB server connection times out.
- **Frontend Stack**: React 18, Vite, React-Leaflet (`frontend/src/components/YatraMap.jsx`), Framer Motion, Tailwind CSS + custom CSS tokens (`frontend/src/index.css`), Recharts.
- **Backend Stack**: Node.js Express ES modules (`backend/app.js`), Port 8000, JWT auth with role-based middleware.
